LANDING PAGE RUANG BIJI — UTS PEMROGRAMAN WEB DASAR

Struktur:
- index.html : struktur/konten website
- style.css  : desain, warna, layout, dan responsivitas
- script.js  : interaksi gambar, filter produk, dan kalkulator penjualan
- assets/images/ : tempat menyimpan gambar lokal jika nanti diperlukan

Cara menjalankan:
1. Ekstrak folder ZIP.
2. Buka VS Code, pilih File > Open Folder, lalu pilih folder UTS_RuangBiji.
3. Buka index.html untuk melihat struktur HTML.
4. Untuk menjalankan website, klik dua kali index.html dari File Explorer
   atau gunakan ekstensi Live Server di VS Code.
5. Gambar saat ini masih memakai URL online, jadi koneksi internet diperlukan.

Catatan:
Harga pada kalkulator adalah contoh untuk demonstrasi. Sesuaikan dengan data tugas.
